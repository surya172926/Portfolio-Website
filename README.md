# Portfolio Website README

## Overview

This is a responsive personal portfolio website built using **HTML** and **CSS**. The website is designed to showcase personal information, skills, projects, achievements, and contact details in a clean and modern layout.

The portfolio helps developers, designers, and students present their professional profile online with an attractive user interface and responsive design.

---

## Features

* Responsive design for desktop and mobile devices
* Modern and clean user interface
* Smooth navigation between sections
* About Me section
* Skills showcase
* Projects gallery
* Contact section with social links
* Simple and lightweight structure using pure HTML & CSS

---

## Technologies Used

* **HTML5** – For website structure
* **CSS3** – For styling and layout
* Flexbox & Grid for responsive design
* Google Fonts and Icons (optional)

---

## Sections Included

1. **Home** – Introduction and welcome section
2. **About** – Personal background and career goals
3. **Skills** – Technical skills and tools
4. **Projects** – Showcase of completed projects
5. **Contact** – Email and social media links

---

## How to Run the Project

1. Download or clone the repository
2. Open the project folder
3. Run the `index.html` file in any web browser
